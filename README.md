# Rutz's PF2e Puzzles

[Discord](https://discord.gg/bB7Ca666Bv) · [Wiki](https://github.com/Rutz179/rutz-pf2e-puzzles/wiki)

Generated puzzles for your table: pick a kind and a difficulty, and the module builds one that can be solved. The players solve it together, each on their own screen.

- **Three brain puzzles** — Code breaker, Light the runes, Memory pairs, at four difficulties. The same puzzle code always makes the same puzzle.
- **Three ways to solve** — checks (a roll earns moves and hints), actions (limited per turn in combat), or free play.
- **Door puzzles** — put a puzzle on a door: it locks, a player who clicks it gets the puzzle, and solving it unlocks the door.
- **GM tools** — give moves and hints, peek at the answer, start over, show it again or end it.

## Install
Foundry → *Add-on Modules* → *Install Module* → Manifest URL:
```
https://github.com/Rutz179/rutz-pf2e-puzzles/releases/latest/download/module.json
```
Foundry VTT v13–v14 · Pathfinder 2e (D&D 5e, Call of Cthulhu 7e and other systems work too) · English / 한국어

The puzzle-piece button in the Rutz toolkit group of the scene controls, or `game.rutzPuzzles.open()`.
